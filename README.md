# Credit Card Risk Analysis

A machine learning project for analyzing credit card risk and assessing credit default or risk patterns.

## Installation & Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mallangithanushreddy-2007/credit-card-risk-analysis.git
   cd credit-card-risk-analysis
   ```

2. **Create and activate a virtual environment:**
   ```bash
   python -m venv venv
   # On Windows:
   .\venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Included Dependencies

- `pandas`
- `numpy`
- `scikit-learn`
- `pyarrow`
- `huggingface_hub`
